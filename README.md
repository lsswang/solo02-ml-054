# Word-form tool and sentence parser

Python 3.11, standard library. Run `python demo.py`. The supplied ordinary baseline supports direct lexical forms/simple plural-s and weighted CFG categories; fixtures contain a finite lexicon and short sentences. This is a new runnable teaching-sized baseline, not an extracted deployed NLP service.

Mature feature-unification and weighted grammar libraries are permitted. NLTK 3.9.2 (Apache-2.0, upstream commit 4e17ea390c526ec9cb9e5ef5eb3733ac118dbb8d) is one available option; no NLTK corpus/model download is required by this exercise.
